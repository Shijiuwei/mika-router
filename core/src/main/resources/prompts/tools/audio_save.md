Save a workspace audio file into the phone's music library (Music/Mika). This is only offered when the user allowed saving; by default the user gets an approval card for each save. The result gives the library path and a content URI. Saving does not send or upload the audio anywhere. If saving is not allowed or the user declines, do not try another way and do not claim it was saved.
