Save a workspace image into the phone's gallery (Pictures/Mika). This is only offered when the user allowed saving; by default the user gets an approval card for each save, so call it once per picture after they asked to save it. The result gives the gallery path and a content URI. Saving does not send or upload the picture anywhere. If saving is not allowed or the user declines, do not try another way and do not claim it was saved.
