Find controls in the current Android accessibility tree by text, resource ID, or role. Returns matching nodes with their parent labels, bounds, and usable refs. You may combine filters; with no filter it lists the first nodes up to limit. This reads text only and does not capture a screenshot. Use the returned snapshotId together with a ref for a later action. If the tree lacks enough information, request a screenshot.
