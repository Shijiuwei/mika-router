Useful when the page shows data loaded from an API: the JSON is often more complete than the screen, and it is where to read numbers the page draws garbled (custom fonts). Only read what the page itself loaded; do not send your own requests to the site's APIs. Recording starts the first time the page is acted on or this tool is used.
