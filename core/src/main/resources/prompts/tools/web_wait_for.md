Wait until something happens on the current tab, at most {{max_seconds}} seconds: text_present / text_absent (page text contains value or not), url_contains (the address contains value), network_idle (no requests for half a second; needs devtools, else devtools_unavailable). Returns met=true when it happened, met=false when the time ran out. Page actions already wait briefly on their own; use this for slower changes.
