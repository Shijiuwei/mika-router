Write UTF-8 text under /workspace (parent directories are created), or to an existing user-granted /folders directory. Granted-folder files are limited to 1 MiB total; creating uses no expectedSha256, updating or appending requires sha256 from the latest read_file. A changed file is refused; read it again and reconcile the changes.
