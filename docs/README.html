从电脑使用

先读从电脑使用 Mika：选 CLI + Skill 还是 MCP、经 USB 还是 Wi-Fi / VPN 连接。选好以后按下面对应的一份做。

文档讲什么
CLI / Skill：安装、升级和卸载在电脑上装 mika 命令或 Agent 用的 Skill
CLI 与 Skill：连接与任务命令连接手机、派任务、查进度、追问和插话的命令
飞书机器人扫码新建、关联已有应用、私聊派任务与收取结果
电脑连接（MCP）让 MCP 客户端把任务交给 Mika：USB、Wi-Fi / VPN、工具、安全
用电脑上的 AI 助手安装写给电脑上的 AI 助手看的安装步骤：手机经 USB 连着电脑时，把这份交给它，它替你装好
