常见问题

简体中文 | English

README 里只放了最常被问到的几条，这里是完整的问答。手机操作设置中每一步的具体报错，见设置指南的「遇到问题」。

安装与上手

只想聊天、上网、处理文件，也要配对无线调试吗？ 不用。配对无线调试只是为了操作手机 App；只聊天、用内置浏览器、在沙箱里处理文件，装好、连上模型就能用，安卓 11 也行。

为什么推荐安卓 14？旧系统能用吗？ Mika 在一块单独的后台屏上操作 App，安卓 12 起可以使用手机操作能力；安卓 12、13 上操作后台屏可能影响主屏焦点。安卓 14 起后台屏有自己的焦点，不会影响你在主屏打字，所以更推荐。只用网页、沙箱和聊天，安卓 11 也能用。

不确定自己的手机行不行？ 设置 › 恢复与修复 › 兼容性自检，一分钟跑完，结果可以一键用设备报告反馈给我们。

APK 更新从哪来？ 只从本仓库的 GitHub Releases 发布。每个版本改了什么，都写在那个版本的发布说明里。App 里「关于 › 检查更新」也能直接下载安装。

手机操作

无线调试自己关掉了？ 安卓原版在 Wi-Fi 断开、手机重启后会关掉无线调试。设置里的「恢复与修复」中「自动打开无线调试」默认开着：需要时 Mika 会自己打开它再连接（要你允许 Mika 修改系统设置）。第一次在某个 Wi-Fi 上，系统会问是否允许，请手动打开一次并勾选「始终允许使用此网络」。如果还是连不上，回到设置里的「设置手机操作」向导重新配对即可。

系统里找不到无线调试？ 有的手机系统去掉了这一项。可以用一台装了 adb 的电脑，经 USB 数据线启动手机助手，见设置指南的「用电脑启动」。

无障碍服务被关掉了？ 系统有时会停掉无障碍服务（比如进程被清理后）。「替我打开无障碍」默认开着，Mika 会自己把它重新打开；修不好时设置页会提示你手动打开。

有的 App 页面读不到、截不到？ 有些页面（比如付款、输密码）禁止截屏，Mika 看不到画面，也不会去识别上面的字。这类页面需要你接管处理，处理好交还给 Mika。

模型

能用自己电脑或局域网里跑的模型吗？ 可以，服务商选「自定义」，填局域网地址即可，见模型与登录。

没有 API Key 能用吗？ 可以用 ChatGPT（Plus / Pro）、xAI / Grok、OpenRouter 账号登录，见模型与登录。

电脑上使用

能从电脑上给 Mika 派任务吗？ 可以，电脑上的 AI 工具通过 CLI + Skill 或 MCP 都行，通常选一种，见从电脑使用 Mika。

语言

App 有哪些语言？ 界面有简体中文、繁體中文、英文、阿拉伯语、波斯语、日语、韩语、西班牙语、葡萄牙语、俄语和印尼语，共 11 种；跟随系统语言（系统语言不在其中时用英文），也可以在 设置 › 语言与外观 › 语言 里切换。内置的 App、网站知识用中文写成，不影响用别的语言和 Mika 说话。

隐私

我的数据发到哪？ 没有 Mika 服务器：你的话、屏幕内容只发给你自己配置的模型服务商；API Key、记忆加密保存在手机上，对话、运行记录只存在本机。详见免责声明与数据隐私。
